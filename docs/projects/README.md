# Learn With Rich Maker Projects · Series 01

Seven projects, one consistent promise: bright illustrations, clickable covers, exact parts lists, pin-by-pin wiring, short steps with checkpoints, starter code, expected results, troubleshooting and safety review.

## Visual and teaching standard
- Learn With Rich owns the brand frame and headings. Covers use a bright cream background, cobalt/teal/coral/yellow, clean friendly maker illustration and one clear hero object.
- Covers are illustrations, never wiring instructions. Wiring diagrams are hand-authored and checked against the exact board revision and component documentation.
- Every project ZIP uses `learnwithrich-resource` v1, with root `manifest.json`, `files/` media, a cover and local Markdown references.
- Keep each step to one action; name both ends of every wire; include an unplugged check and the expected result.
- Include inventory, tools, exact setup, code, tests, troubleshooting, glossary and printable checklist.
- No beginner project includes household mains wiring. Redesign as low-voltage demos or exclude it.

## Series
1. **Wi-Fi Room Comfort Controller** — Arduino UNO R4 WiFi, DHT22, LCD and 5V relay; automatic 5V fan and local Wi-Fi monitor. This ZIP is included here.
2. **Plant Pal** — soil-moisture readings, a screen and a small 5V pump; calibration card and pump test in a cup.
3. **Window Weather Buddy** — temperature, humidity and pressure display with a simple daily logging sheet.
4. **Desk Light Helper** — light sensor and low-voltage LED with manual override.
5. **Doorway Visitor Chime** — PIR motion sensor, buzzer and status light; explain blind spots and privacy.
6. **Mini Greenhouse Watcher** — temperature/soil checks and a low-voltage fan, reusing skills from projects 1 and 2.
7. **Room Air Monitor** — particulate/air sensor display with a plain-language guide to what the sensor can and cannot tell you.

Project 1 is a complete single-resource ZIP. The other six are a roadmap and need hardware-specific diagrams and reviewed build guides before packaging.
